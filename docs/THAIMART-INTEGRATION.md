## ทำแล้ว

- ตั้งค่า CHECKOUT_HOSTS เป็น thaimart.com ใน staging configuration
- บันทึก URL ใน tests/fixtures/thaimart-urls.json โดยไม่เพิ่มสินค้าใดลงฐานข้อมูลผู้ใช้
- ทดสอบบันทึก URL ผ่าน API และ redirect กลับไป URL เดิมทั้งสามรายการ รวม ?share=true
- ทดสอบปฏิเสธ HTTP, โดเมนเลียนแบบ และ URL ที่ใช้ userinfo หลอกชื่อโดเมน
- IMPORT_HOSTS ยังว่าง จึงยังไม่เปิดการดึงข้อมูลต้นทางอัตโนมัติ

## สิ่งที่ยังยืนยันไม่ได้

เครื่องมืออ่านเว็บเปิด URL ทั้งสามไม่ได้ และ HTTP request จากสภาพแวดล้อมทำงานได้ 403 Forbidden ทั้งสามรายการ ไม่ได้ยืนยันว่าเว็บใช้โครงสร้างใด มี JSON-LD หรือ API หรือไม่ และไม่ทราบสาเหตุของ 403 ที่แน่ชัด

ยังไม่มีข้อมูลชื่อสินค้า ราคา รายละเอียด รูป หรือสต็อกที่ตรวจสอบจากต้นทางได้ ชื่อสินค้าใน automated test เป็นข้อมูลสมมติที่ระบุชัด ไม่ใช่ข้อมูลของสินค้าจริง

การทดสอบ redirect ตรวจ response Location ในระบบเราเท่านั้น ไม่ได้ยืนยันการโหลดหน้าปลายทางหรือการ checkout จริง

## ขั้นต่อไป

เมื่อเข้าถึง Cloudflare staging ได้ ให้ทดสอบการร้องขอ URL ตัวอย่างจาก runtime จริงอย่างจำกัด หากอ่านไม่ได้ให้ใช้ API/การส่งออกข้อมูลที่ต้นทางรองรับ หรือไฟล์ข้อมูลที่ร้านมีสิทธิ์ใช้งาน ไม่หลบมาตรการป้องกันของต้นทาง

เมื่อมี response ที่อ่านได้และสิทธิ์ใช้งานชัดเจน จึงเขียน adapter จากโครงสร้างจริงและเปิด IMPORT_HOSTS การนำเข้ารูป, AI และการ sync อัตโนมัติยังเป็นงานต่อไป
